# Teknologi Informasi UMY

An Android application introducing the Information Technology program at Universitas Muhammadiyah Yogyakarta (UMY).

This project is built using Kotlin and Jetpack Compose in Android Studio.

## Features

- Displays the Information Technology program title.
- Presents Universitas Muhammadiyah Yogyakarta branding.
- Uses a green-and-gold design with the university seal.

## Technologies

- Kotlin
- Android Studio
- Jetpack Compose

## How to Run

1. Clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Run the application on an Android emulator or device.
